# MEDHAVI — Portfolio Website

A complete plain HTML/CSS/JavaScript portfolio inspired by the supplied dark editorial design reference.

## Files
- `index.html` — complete website structure and content
- `style.css` — responsive monochrome editorial design
- `script.js` — menu and subtle interactions

## Run locally
1. Keep all three files in the same folder.
2. Double-click `index.html`.
3. It opens directly in your browser.

## Deploy
You can upload the three files to GitHub Pages, Netlify, Vercel, or any normal static hosting service.
